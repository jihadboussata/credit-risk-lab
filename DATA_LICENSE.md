# Dataset attribution and reuse

Source: **Default of Credit Card Clients**, I-Cheng Yeh (2009),
UCI Machine Learning Repository. DOI: [10.24432/C55S3H](https://doi.org/10.24432/C55S3H).

Dataset page: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients

UCI distributes the dataset under the
[Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).
The dataset is not covered by this repository's MIT software license.

Raw and processed source data are downloaded locally and excluded from Git.
Published aggregate analyses, figures, split assignments, and prediction tables
are derived from that source. Transformations include canonical column names,
engineered payment-history features, a stratified partition and model scores.
No synthetic example in `data/examples/` is an actual customer record.

Original research: Yeh, I.-C. and Lien, C.-H. (2009), *The comparisons of data
mining techniques for the predictive accuracy of probability of default of
credit card clients*, Expert Systems with Applications 36(2), 2473–2480.
https://doi.org/10.1016/j.eswa.2007.12.020

Source data reflect Taiwan in 2005. No endorsement by UCI, IBM or a financial
institution is implied. See `docs/data_dictionary.md` for coding ambiguities.
